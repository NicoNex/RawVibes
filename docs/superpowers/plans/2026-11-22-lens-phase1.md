# Lens Corrections (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A complete Lens section for RAWs: lensfun profile (automatic or chosen) correcting distortion, TCA and vignetting with amounts, plus manual distortion, vignetting with midpoint, CA red/blue, automatic CA and defringe.

**Architecture:** A build-time script turns the lensfun XML database into JSON. `core/src/lensdb.rs` finds the lens and interpolates its calibration as lensfun does; `core/src/lens.rs` turns it, the image size and the user's amounts into a `Correction` (plain numbers) that the RAW develop shader applies per output pixel (inverse mapping, as lensfun corrects). The GTK Lens section drives it.

**Tech Stack:** Rust (core + relm4/GTK), WGSL (`core/src/raw.wgsl`), Python 3 stdlib (DB conversion), C (dev-only reference harness against the installed liblensfun 0.3.4).

**Spec:** `docs/superpowers/specs/2026-11-22-lens-perspective-design.md` (phase 1 only)

## Global Constraints

- Port lensfun 0.3.4 maths exactly (`modifier.cpp` normalisation and `get_hugin_focal_correction`, `mod-coord.cpp` distortion models ptlens/poly3/poly5, `mod-subpix.cpp` TCA linear/poly3, `mod-color.cpp` vignetting pa, `lens.cpp` Interpolate*). Reference sources: github.com/lensfun/lensfun tag v0.3.4. No home-grown approximations for profile corrections.
- Known-answer tolerance against liblensfun: 1e-4 in normalised coordinates, 1e-4 relative on vignetting gains.
- No new Rust crates. DB conversion in Python stdlib only.
- Database: generated from `/usr/share/lensfun/version_1` into `target/lensfun.json`, installed to `$(PREFIX)/share/rawvibes/lensfun.json`; licence CC-BY-SA 3.0 noted. Missing DB never breaks anything: profile row says so.
- Distortion correction always auto-scales so no empty corners show (lensfun `GetAutoScale` approach, extended to the manual distortion).
- Manual ranges: distortion −100…100, vignetting −100…100 (existing `lens_vignette`), midpoint −100…100, CA red/cyan and blue/yellow −100…100; profile amounts 0–100 % (default 100).
- Every new string through gettext and translated in `po/it.po`. Commit per task (push at the end). `cargo clippy --all-targets` clean, `cargo fmt`.

## Review Focus

1. Lens not in the database (Helios 44-2) → profile row "None found", manual corrections fully usable; test `unknown_lens_has_no_profile` (Task 2).
2. EXIF without focal length or aperture (manual lens) → automatic profile uses the user's typed focal/aperture; with none typed, the profile is not applied (no guessing); test `profile_needs_a_focal_length` (Task 3).
3. Camera not in the database (new body) → crop factor from the lens calibration is used (lensfun's fallback: `lens.CropFactor`), still corrects; test `unknown_camera_uses_the_lens_crop` (Task 3).
4. Portrait RAWs (EXIF orientation 6/8) → normalisation uses the sensor's long/short side, not the displayed one; test `portrait_matches_landscape` (Task 3).
5. Old sidecars → all new fields default to "no change" except profile amounts 100 %, applied only when a profile is found; test `old_sidecar_has_neutral_lens` (Task 4).

### Task 3: `core/src/lens.rs` — the correction

**Files:** Create `core/src/lens.rs`; modify `core/src/develop.rs` (`Detail` fields, `DevPart::Lens` neutral).

**Interfaces:**
- Consumes: `Calib`, `Camera`, `Lens` (Task 2).
- Produces:
  - `#[derive(Clone, Copy, Debug, Default, PartialEq)] pub struct Correction` — plain numbers the shader needs: normalisation scale (lensfun `NormScale` incl. crop-factor ratio and `get_hugin_focal_correction`), distortion model id + 3 terms × amount, TCA model id + terms, vignetting k1..k3 × amount, manual distortion k, manual vignette amount + midpoint, manual CA red/blue scales, auto-scale. `Default` = identity.
  - `pub fn correction(calib: Option<&Calib>, d: &Detail, sensor: (u32, u32), lens_crop: f32, camera_crop: Option<f32>) -> Correction`
  - `impl Correction { pub fn source(&self, p: [f32; 2], channel: usize) -> [f32; 2]; pub fn gain(&self, p: [f32; 2]) -> f32 }` — CPU reference of exactly what the shader does: `p` in sensor pixels (corrected image), returns the sensor pixel to sample for channel 0/1/2, and the vignetting gain. The shader mirrors these lines one to one.
  - `Detail` new fields (serde default): `lens_dist_amount: f32` (100), `lens_vig_amount: f32` (100), `lens_tca: bool` (true), `lens_distortion: f32` (0), `lens_vignette_mid: f32` (0), `lens_ca_red: f32` (0), `lens_ca_blue: f32` (0), and `#[serde(skip)] pub lens: Correction` (computed by the app, never saved). `DevPart::Lens.neutral` resets all of them (existing `lens_vignette`, `ca_correct` too) and moves `defringe`/`defringe_green` from `Detail` part to `Lens` part.
- Manual formulas (pinned): distortion `r_src = r·(1 + k·r²)`, `k = −0.25·distortion/100`, `r` normalised as lensfun (half the short side = 1) — positive slider pulls a corner's source towards the centre (corrects barrel); manual vignette keeps today's gain `1 + a·r²(1 + r²)` with `r²` scaled by `2^(−mid/50)`; CA: R sampled at `r·(1 + 0.002·ca_red/100)`, B at `r·(1 + 0.002·ca_blue/100)`.
- Auto-scale: lensfun `GetAutoScale` (bisection on the image border's mapped points), applied to the combined profile + manual distortion; never > 1 shrink of content beyond what the border needs.
- [ ] **Step 1: tests:** `source_matches_lensfun` (every reference case's 9 points × 3 channels within 1e-4 normalised), `gain_matches_lensfun`, `autoscale_matches_lensfun`, `profile_needs_a_focal_length` (focal 0 → profile terms identity), `unknown_camera_uses_the_lens_crop`, `portrait_matches_landscape` (4000×6000 gives the transposed results of 6000×4000), `identity_is_identity` (`Correction::default().source(p, c) == p`, gain 1), `manual_distortion_sign` (positive distortion: a corner's source is nearer the centre), sweep `amount_zero_is_identity` over all reference lenses.
- [ ] **Step 2:** FAIL. **Step 3:** implement. **Step 4:** PASS. Commit "Lens corrections: lensfun's models and manual ones".
