Symbolic icons for the Qt interface, bundled as Qt resources (`qrc:/icons/…`).

- `*-symbolic.svg` from the GNOME Adwaita icon theme: CC BY-SA 3.0 or LGPL-3.0.
- `magic-wand`, `camera-shutter`, `tag-outline`: from relm4-icons (GNOME Icon Development Kit), as the GTK interface uses them.
- `rawvibes-*`: RawVibes' own (`data/icons`).
