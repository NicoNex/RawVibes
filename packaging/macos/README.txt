RawVibes for macOS

RawVibes is not signed with an Apple Developer ID, so macOS blocks it
the first time. To install it:

1. Drag RawVibes.app to the Applications folder.
2. Open Terminal and run:
   xattr -cr /Applications/RawVibes.app
3. Open RawVibes from Applications.

To open a photo with RawVibes, right-click it in Finder and choose
Open With > RawVibes.
